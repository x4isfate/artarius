# Artarius

Модуль Foundry VTT для системы [«Витрувий»](https://github.com/x4isfate/vitruvium): общая карта мира для политической игры, где игроки играют богами и вместе с мастером меняют мир. Foundry 14 (проверено на 14.370), система `vitruvium` 0.2.5 и новее. Интерфейс на русском и английском.

## Установка

В Foundry: «Модули» → «Установить модуль» → в поле «URL манифеста» вставить
`https://github.com/x4isfate/artarius/releases/latest/download/module.json`.

## Что умеет

Подробное руководство: [docs/GUIDE.md](docs/GUIDE.md). То же самое открывается в Foundry кнопкой «Как играть» в группе «Карта мира».


На сцене появляется группа «Карта мира» в панели слева.

- Объекты: города, крепости, святилища. Значок, цвет и размер берутся из типа.
- Линии: реки сужаются к истоку и петляют, дороги рисуются пунктиром с обводкой.
- Области: закрашиваются по клеткам сетки, с Alt рисуется свободный контур. Область лежит на слое. Режим «Поверх» оставляет под ней чужую землю: так видна спорная территория.
- У любого элемента есть название, описание, демиург, статусы с уровнями вроде 7/10, аспекты со своими статусами и связи с другими элементами. У области лист показывает, какие объекты стоят на её земле.

- Меню быстрых действий слева снизу: каждый выбирает свои кнопки и макросы, мастер задаёт набор по умолчанию.
- Azgaar's Fantasy Map Generator: генератор открывается в Foundry, полный JSON-экспорт превращается в страны, провинции, города, реки и дороги, картинка карты становится фоном.

Мастер правит карту сразу. Правки игрока сначала попадают в его черновик, другие игроки их не видят. Игрок отправляет черновик заявкой с названием и пояснением. Мастер в окне «Заявки» смотрит правки на карте, принимает или отклоняет сразу несколько заявок, а по спорной назначает проверку сложностью 1–6. Игрок бросает её по карточке в чате обычной проверкой Витрувия. При успехе заявка принимается сама, это отключается в настройках. Если карта успела измениться после подачи заявки, очередь это покажет, и мастер решит, применять правку поверх или пропустить.

Данные лежат в журнале «Атлас: <сцена>», по странице на элемент. Типы и слои мастер настраивает кнопкой «Типы и слои». Расширения подключаются через `game.modules.get("artarius").api`, описание в [docs/API.md](docs/API.md).

## Разработка

```sh
npm install
npm run lint   # синтаксис, шаблоны, переводы, ссылки релиза, обработчики кнопок
npm test       # геометрия, заявки, импорт Azgaar
npm run dist   # архив в dist/
```

Релиз: поднять `version` и ссылку `download` в `module.json`, дописать раздел `## X.Y.Z` в `CHANGELOG.md` и влить в `main`. GitHub Actions сам соберёт архив и опубликует релиз `vX.Y.Z`, после этого Foundry покажет кнопку обновления. `npm run lint` проверяет, что ссылки и раздел журнала на месте.

Для разработки удобно сделать ссылку из `Data/modules/artarius` на папку репозитория.
