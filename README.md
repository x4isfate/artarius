# Artarius

Модуль Foundry VTT для системы [«Витрувий»](https://github.com/x4isfate/vitruvium): общая карта мира для политической игры, где игроки играют богами и вместе с мастером меняют мир. Foundry 14 (проверено на 14.370), система `vitruvium` 0.2.5 и новее. Интерфейс на русском и английском.

## Установка

В Foundry: «Модули» → «Установить модуль» → в поле «URL манифеста» вставить
`https://github.com/x4isfate/artarius/releases/latest/download/module.json`.

## Что умеет

Подробное руководство: [docs/GUIDE.md](docs/GUIDE.md). То же открывается в Foundry кнопкой «Как играть» в группе Артария слева.

- Сцена Артария: плоский мир из гексов. Мастер создаёт её кнопкой «Мир Артария» во вкладке «Сцены» или включает режим в настройках своей сцены с гекс-сеткой.
- Четыре инструмента, работает один за раз. Осмотр ставит на выбранный гекс кнопки, как у токена в Foundry, а подробности открывает в окне по кнопке. Зона прикрепляет выбранные гексы к новой или существующей зоне. Метка ставит город или храм на каждый выбранный гекс. Линия проводит реку или дорогу по точкам, без привязки к гексам.
- Несколько меток на гексе ложатся группой, как в Civilization V, со счётчиком сверху. Метку можно перетащить на другой гекс мышью.
- Своя библиотека из 130 с лишним значков, которые красятся цветом типа или отдельной метки, и загрузка своих картинок.
- Типы и слои. Готовый набор местности, держав, меток и линий, свои типы добавляются прямо из панели. В слоях «Местность», «Области» и «Владения» гекс принадлежит одной зоне, в «Прочем» зоны накладываются.
- У каждой зоны, метки и линии есть название, описание, демиург, статусы с уровнями вроде 7/10 и аспекты со своими статусами. Статус превращается в аспект одной кнопкой.
- Ходы: рисуют все, заявку отправляет только тот, чей ход, ход передаёт мастер.
- Генератор мира из «кусочков»: материки, острова и хребты по рецепту, плавные биомы, ресурсы, нейтральные объекты и стартовые державы игроков. «Новый мир» — одной кнопкой.
- Размер карты в гексах и размер гекса меняются в «Настройках мира». Берега можно рисовать волнистыми, данные при этом остаются по гексам.
- Линии свободно, по гексам или от руки. Штриховки зон и наборы слоёв, как в Azgaar.
- Панели — обычные окна Foundry: двигаются, растягиваются, темы интерфейса оформляют их как свои.
- Azgaar's Fantasy Map Generator: генератор открывается в Foundry, полный JSON-экспорт ложится на гексы сцены местностью, державами, городами, реками и дорогами.

Мастер правит мир сразу. Правки игрока сначала лежат в его черновике, другие игроки их не видят. Игрок отправляет черновик заявкой. Мастер смотрит правки на карте, принимает или отклоняет сразу несколько заявок, а по спорной назначает проверку Витрувия сложностью 1–6. Если мир успел измениться после подачи заявки, очередь это покажет.

Данные лежат в журнале «Атлас: <сцена>», по странице на элемент. Расширения подключаются через `game.modules.get("artarius").api`, описание в [docs/API.md](docs/API.md).

## Значки

Встроенные значки меток взяты с [game-icons.net](https://game-icons.net) (Lorc, Delapouite и другие авторы) по лицензии [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Значки перекрашены в белый, чтобы Foundry мог красить их цветом типа. Полный список авторов: [assets/icons/CREDITS.md](assets/icons/CREDITS.md).

## Разработка

```sh
npm install
npm run lint   # синтаксис, шаблоны, переводы, ссылки релиза, обработчики кнопок, поля ApplicationV2
npm test       # правила мира, геометрия, заявки, импорт Azgaar
node tests/harness/e2e.cjs   # интерфейс на стенде в Chromium, без Foundry
npm run dist   # архив в dist/
```

Релиз: поднять `version` и ссылку `download` в `module.json`, дописать раздел `## X.Y.Z` в `CHANGELOG.md` и влить в `main`. GitHub Actions сам соберёт архив и опубликует релиз `vX.Y.Z`, после этого Foundry покажет кнопку обновления. `npm run lint` проверяет, что ссылки и раздел журнала на месте.

Для разработки удобно сделать ссылку из `Data/modules/artarius` на папку репозитория.
