# Изменения

## 0.2.0

- Обновление одной кнопкой. Релиз на GitHub собирается сам, когда в `module.json` поднимается версия. Foundry видит новую версию и показывает кнопку обновления у модуля. Мастер в мире получает сообщение, что вышла новая версия (отключается в настройках).
- Меню быстрых действий слева снизу: карта, инструменты рисования, заявки со счётчиком, поиск по карте, типы и слои, Azgaar, руководство. Каждый игрок сам выбирает кнопки и их порядок, может добавить свои макросы. Мастер может сделать свой набор набором для всех.
- Azgaar's Fantasy Map Generator. Генератор открывается окном прямо в Foundry. Импорт полного JSON-экспорта: страны, провинции, города, реки, дороги и морские пути становятся элементами карты. Картинка карты ставится фоном сцены. Повторный импорт заменяет прошлый.
- Лист объекта показывает, на земле каких областей он стоит. Области к объектам не привязаны, принадлежность считается по положению на карте.
- API для модулей-расширений: свои кнопки в меню, хуки на правки и заявки, поле `ext` у элементов для своих данных. Описание в [docs/API.md](docs/API.md).
- Проверка кнопок в `npm run lint`: у каждой кнопки в шаблонах есть обработчик.

## 0.1.1

- Окно «Как играть»: открывается при первом входе и кнопкой со знаком вопроса в группе «Карта мира». Текст тот же, что в [docs/GUIDE.md](docs/GUIDE.md).
- Ошибки модуля больше не пропадают молча: модуль показывает красное сообщение с текстом ошибки, подробности уходят в консоль.

## 0.1.0

- Первая версия. Объекты, реки и дороги, области на гексах и свободным контуром, слои, типы с общим видом. Игроки предлагают правки заявками, мастер принимает, отклоняет или назначает проверку Витрувия.
